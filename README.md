# Space City Racing

A 3D racing game set in a space city.

## Tools

| Job | Tool | Status |
|---|---|---|
| Game engine | **Unreal Engine 5** (Blueprints first, C++ later if needed) | ⏳ You install it (step 1) |
| 3D modeling | **Blender 5.3** | ✅ Installed at `E:\Blender` |
| Launcher | **Epic Games Launcher** | ✅ Already had it |
| Version control | **Git + Git LFS** | ✅ Repo set up in this folder |

## Step 1: Install Unreal Engine on the E: drive

> ⚠️ **Your C: drive only has about 5 GB free.** Unreal needs 60 GB or more, so install it on **E:**.

1. Open the **Epic Games Launcher** and sign in.
2. Go to **Unreal Engine** (left sidebar), then the **Library** tab.
3. Next to **Engine Versions**, click **+** and pick the newest **5.x** version.
4. Click **Install**. When it asks for a location, choose **`E:\Epic Games`**.
5. Before confirming, click **Options** and **untick** what you don't need yet. This saves a lot of space:
   - **Editor symbols for debugging** (this one is huge)
   - **Android**, **iOS**, **Linux** target platforms (you can add them later)
6. Wait for the download to finish. It's big.

## Step 2: Create the project from the Vehicle template

The Vehicle template already gives you a drivable car on a test track, so it covers the "car on a flat track" first test.

1. In the Library, click **Launch** on the engine version you installed.
2. In the Project Browser, choose **Games**, then **Vehicle**.
3. Settings:
   - **Blueprint** (not C++)
   - **Starter Content**: on
   - **Location**: `E:\space city racing`
   - **Name**: `SpaceCityRacing`
4. Click **Create**.
5. Press **Play** (or Alt+P) and drive with **W A S D**. If the car drives, the setup is complete.

## Step 3: Keep Unreal's cache off the C: drive

Unreal stores a large shader cache in your user folder on C: by default. The `UE-LocalDataCachePath` setting in your Windows user environment points it at `E:\UnrealCache` instead. Restart the launcher or editor after it's set so the change takes effect.

To check or undo it later, search Windows for **"Edit environment variables for your account"**.

## Blender → Unreal workflow

### The space car (`SK_SpaceCar`)

The car is generated by a script, so you can tweak numbers and rebuild in seconds:

- **Script:** `Art/Blender/scripts/build_space_car.py`. Body shape, canopy, wheel size and position, and colours are all defined near the top.
- **Editable file:** `Art/Blender/SpaceCar.blend`. Open it in Blender to look around or tweak by hand.
- **Unreal file:** `Art/Exports/SK_SpaceCar.fbx`. A skeletal mesh at 1 unit = 1 cm, with bones `Root`, `Phys_Wheel_FL`, `Phys_Wheel_FR`, `Phys_Wheel_BL`, `Phys_Wheel_BR`.

> **Why the car matches the template sports car:** the space car reuses the Vehicle template's `SK_SportsCar` skeleton, its wheel animation and its physics body. That only works if the bones match the template exactly: the **same names, positions and rotations**. Wheels are at x=135 / -129.2, y=±90, with 39 cm front and 40 cm rear radius. If a bone's rotation differs, the animation tips the whole car over. If a wheel position differs, the physics joints flip it. `build_space_car.py` already handles all of this. Keep the `WHEELS` values as they are unless you also make new physics.

Rebuild after changing the script (from the repo folder):

```bash
"E:/Blender/blender.exe" -b --factory-startup --python-exit-code 1 -P "Art/Blender/scripts/build_space_car.py" -- "." "Art/Renders"
```

### Getting the car into Unreal

`SpaceCityRacing/Scripts/setup_space_car.py` imports the FBX and sets up everything in `Content/SpaceCar`:
- the materials, including glows
- the mesh, on the template skeleton
- the wheels: 34 cm radius, 30 cm wide
- **BP_SpaceCar**, which it also makes the car you drive

It's safe to re-run after changing the car in Blender. **Close the Unreal editor first**, then run from the repo folder:

```bash
"E:/Epic Games/UE_5.8/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "SpaceCityRacing/SpaceCityRacing.uproject" -run=pythonscript -script="SpaceCityRacing/Scripts/setup_space_car.py" -unattended -nosplash -NullRHI
```

`verify_space_car.py` (same command, different script) reports what's saved, without changing anything.

### The space city track (`Lvl_SpaceCity`)

A 1.5 km night circuit through about 600 neon skyscrapers. This is the map the game and editor open with.

- **Script:** `Art/Blender/scripts/build_space_city.py`. The track's shape is the `CONTROL` list of points at the top, and road width, curbs, barriers and city density are set there too. Change `SEED` for a different city layout.
- **Editable file:** `Art/Blender/SpaceCity.blend`
- **Unreal files:** `Art/Exports/SpaceCity/`. Road, barriers, four building blocks and the ground, plus `track_info.json` with the start position.

Rebuild in Blender, then in Unreal (close the editor first):

```bash
"E:/Blender/blender.exe" -b --factory-startup --python-exit-code 1 -P "Art/Blender/scripts/build_space_city.py" -- "." "Art/Renders"
```

```bash
"E:/Epic Games/UE_5.8/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "SpaceCityRacing/SpaceCityRacing.uproject" -run=pythonscript -script="SpaceCityRacing/Scripts/setup_space_city.py" -unattended -nosplash -NullRHI
```

The Unreal script also sets up the night look (moonlight, thin fog, locked exposure) and the start position. Lighting values are near the top of `build_level()`.

### Other models you make by hand

1. Model in **real-world meters** (Blender's default). A car is about 4.5 m long.
2. Select the object and press **Ctrl+A, then All Transforms** to apply the scale.
3. Save the source file to `Art/Blender/`.
4. Go to **File → Export → FBX** and save to `Art/Exports/`. In the export options, set **Apply Scalings: FBX Units Scale**.
5. In Unreal, drag the `.fbx` into the Content Browser.

> Anything with **bones** (vehicles, characters) needs extra care. Name the armature object `Armature`, and export at 1 unit = 1 cm. The car script shows how.
